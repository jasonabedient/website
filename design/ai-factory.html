The Workflow

Zero-friction handoff from bug report to human inspection.

UI polish bugs, scroll flickers, and layout regressions often sit in backlog triage because context-switching is expensive. With AI Factory, designers and engineers file a clear Jira ticket with reproduction steps, apply the C3 Code Factory label, and let autonomous agents handle the implementation loop.

1

Label in Jira

Add the C3 Code Factory label to any Jira issue (e.g. PLAT-160847) with steps to reproduce.

2

Agent Queue

Ticket auto-ingests into the Queued column and provisions a workspace agent (Starting agent).

3

Autonomous Fix

Agent moves to In Process, reproduces the issue, writes the code fix, and opens a pull request.

4

Inspection Queue

Order lands in Inspection with a live Preview link so a developer can verify and merge.

Live Queue Triage

Watching labeled Jira tickets spin up agents in real time.

As soon as tickets are tagged with C3 Code Factory, they populate the Queued column on the Factory board. Team members can filter the board by assignee initials at the top, monitor run count and dollar cost per card, and launch a live preview environment directly from the card footer.

C3 Code · Factory Board — Queued Column
3 Orders Queued

Instant Jira synchronization

Each card links both the local issue key (CODE-622, CODE-620, CODE-621) and the platform Jira ticket (PLAT-160847, PLAT-160846, PLAT-160845) alongside priority badges.

Live agent lifecycle status

Cards display the target application (C3 Code - Genesis) and real-time provisioning state (Starting agent) before transitioning to In Process.

Transparent run & cost telemetry

Every order tracks agent attempts and compute spend (0 runs · $0.00 at queue time, updating as tokens are consumed) so teams can audit ROI across the fleet.

One-click developer verification

Once the agent finishes its run and moves the card to the Inspection column, the Preview button opens the running sandbox build for human sign-off.

Real Tickets Sent to the Factory

Filing UX polish bugs for autonomous resolution.

Here are two of the actual UI bugs captured and labeled C3 Code Factory in the queue above—demonstrating how visual interaction glitches are documented and handed off to the agents.

Home Prompt Input Sizing
CODE-622 P2 PLAT-160847
C3 Code | Home prompt text area is too small for multi-line prompts. When pasting or typing a prompt longer than ~2 lines on the Home screen ("What do you want to create?"), the text area constrains visibility instead of expanding smoothly. Tagged C3 Code Factory and queued for an agent fix.
Chat Scroll-to-Bottom Flicker
CODE-621 P2 PLAT-160845
C3 Code | Chat flickers badly when clicking the "scroll to bottom" arrow. During or after a long agent response in a workspace chat, scrolling up and clicking the ↓ jump-to-bottom button triggers severe layout/scroll Thrashing. Tagged C3 Code Factory for autonomous debugging and verification.
